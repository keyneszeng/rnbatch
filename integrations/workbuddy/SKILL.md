# 批量重命名（关键词一致化）

## 分工

- **关键词由你（AI）判断** —— 读正文，理解哪串词才是项目名/人名/公司简称。
- **批量改名由 `rnbatch` 做** —— 模板、补零、冲突消解、两阶段改名、撤销日志。

前置条件：`rnbatch` 已在 PATH 里（`pip install -e ".[all]"` 后即得）。

## 优先用 MCP 工具，其次用 CLI

如果会话里已经挂了 `rnbatch` 的 MCP server（工具名 `list_files` / `extract_text` /
`preview_rename` / `apply_rename` / `undo_rename` / `recent_renames`），**直接调工具**，
不用走命令行 —— 返回值是结构化 JSON，比解析 stdout 可靠。

只有 MCP 不可用时，才用下面的 CLI 流程。

配置方式见仓库 `docs/AGENT.md`。

## 标准流程

### 1. 摸清文件夹

```bash
ls -la "<目标目录>"
```

### 2. 抽取基准文件正文（不要跳）

```bash
rnbatch extract "<基准文件>" --limit 3000
```

支持 `.docx .doc .rtf .pptx .xlsx .pdf .txt .md .csv`；**图片走 OCR**（macOS Vision，离线）。

命令末尾会打印**候选关键词**（带分值和依据）。它只是启发式，供你参考，
不要照抄 —— 你读过正文，判断比它准。

基准文件不明确时抽几个候选：

```bash
rnbatch extract "<目录>" --max-files 4 --limit 1500
```

### 3. 判断关键词，向用户确认

从正文里挑出最像「项目名/人名/公司名」的那一串，**复述给用户再动手**：

> 从「会议纪要.docx」读到：主题是「星海中心项目 一期交付启动会」，甲方恒远置业集团。
> 我打算用 **星海中心** 作命名词，模板 `{kw}-{n:02}`，对吗？

**不要自己拍板就改。** 关键词选错，一百个文件全错。

### 4. 预览（必做）

```bash
rnbatch preview "<目录>" --kw "星海中心" --template "{kw}-{n:02}"
```

把预览表原样贴给用户看。

### 5. 执行

```bash
rnbatch apply "<目录>" --kw "星海中心" --template "{kw}-{n:02}"
```

输出会给出撤销命令 —— **必须把撤销命令告诉用户**。

### 6. 后悔就回滚

```bash
rnbatch undo            # 最近一次
rnbatch undo <日志名>    # 指定批次
```

## 模板

| 占位符 | 含义 |
|---|---|
| `{kw}` | 关键词 |
| `{n}` / `{n:03}` | 序号（自动宽度 / 强制补零） |
| `{orig}` | 原文件名（不含扩展名） |
| `{date}` | 文件修改日期 |
| `{type}` | 中文类型标签（照片/PDF/文档/表格/演示） |
| `{ext}` | 扩展名（不写也自动保留） |

常用：`{kw}-{n:02}`（通用）、`{kw}-{n:02}-{type}`（混合格式）、`{kw}-{orig}`（保留原名信息）。

## 参数

`--sort name|date|mtime_desc|size`、`--start N`、`--pad N`、`--recursive`、`--only pdf,jpg`

## 安全规则（不可违反）

1. **先 preview，后 apply。** 没有例外。
2. **关键词必须由用户确认。**
3. **每次 apply 都写撤销日志**（`~/.rnbatch/undo/`），回滚命令主动告诉用户。
4. **不要在系统目录、桌面/下载根目录上直接跑 `--recursive`。**
5. 改名是原地操作，不复制；跨卷会失败，脚本会回滚。

## 排查

| 现象 | 处理 |
|---|---|
| `（图片无可识别文字）` | 图太糊或纯图无文字，改从别的文件取词 |
| `（解析失败…）` | 加密 / 损坏 / 扫描版 PDF 无文字层。`extract` 会自动顺延到下一个文件 |
| 预览里标 `!` / **`preview` 退出码 3** | 目标名已被目录里别的文件占用。**不要接着跑 `apply`**，它一定会被拒绝，一个文件都不碰。换模板、加 `--start`，或先把占位文件挪走 |
| `ⓘ 跳过 N 个符号链接` | 正常行为。改链接名会让它指向的原文件也改名，链接当场断 |
| `⚠ N 个名字超过 200 字节，已自动截断` | 关键词或 `{orig}` 太长。换个短点的关键词 |
| `❌ 没有写权限` | 目录不可写，换位置或改权限 |

## 退出码

| 码 | 含义 |
|---|---|
| `0` | 成功 |
| `1` | `apply` 失败，已尽力回滚 |
| `2` | 用法错误 / 路径不存在 / 没有可处理的文件 |
| `3` | `preview` 发现目标名被占用 |

在脚本里判断：`rnbatch preview ... && rnbatch apply ...`，`preview` 非 0 就别往下走。
