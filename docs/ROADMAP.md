# Roadmap · Web App 优先（2026-10-29）

> 产品方向已从「先做 macOS 桌面包」改为 **Web App 优先**。浏览器即用户界面，
> CLI/MCP 继续提供底层能力。独立 macOS .app **暂不排期**。

## 产品目标

让用户通过浏览器完成：
**上传文件/文件夹 → 读取正文推荐关键词 → 调整命名模板 → 预览冲突 → 确认执行 → 下载 ZIP**。

浏览器源文件只读；重命名执行在服务端隔离的临时副本上进行。

## v0.3 · Web App MVP（开发中）

- [x] 浏览器直接选择多个文件或文件夹，摆脱 osascript / 路径输入
- [x] 创建隔离的临时工作区，限制 200 文件 / 100 MB 总量 / 25 MB 单文件
- [x] 从上传的 Office / 文本 / 图片材料提取候选关键词（取决于可选依赖）
- [x] 工作区预览 token + 执行前校验文件快照
- [x] 重命名结果 ZIP 下载，按文件夹层级打包
- [x] 工作区撤销、主动删除、闲置过期清理
- [x] 上传路径穿越防护、文件大小限制、按工作区隔离撤销日志
- [ ] 真实浏览器 E2E（Chrome / Safari / Edge）
- [ ] 更大文件的分块上传、暂停续传及进度条
- [ ] 扫描版 PDF OCR 的跨平台方案与资源限额
- [ ] 失败事务的可视化恢复及工作区保留机制

- [ ] 对象存储 / 独立工作进程 / 任务状态 / 定时销毁；文件保留与删除政策

## 近期不做

- 独立 macOS .app / Tauri / py2app：不是现阶段产品交付路径
- 微信小程序：保留未来集成可能，不作为当前 MVP
- 在未建立账户隔离、上传处理与清理策略前直接开放公网
- 没有人或 Agent 确认就自动做不可逆批量改名

## 兼容方式

命令行与 MCP 继续支持本地文件操作，Web 端旧版「输入服务器本地路径」收在高级模式内。
普通浏览器用户通过上传临时副本的方式操作；两条路径复用同一个命名引擎。
