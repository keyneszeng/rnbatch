## 3. 过程中发现的问题

第一次脚本运行有 **1 个测试工具故障**：测试脚本里的 Python ZIP 检查代码将字典键误写成未加引号的变量（`NameError`），并不是产品服务报错。修复后重新运行，13/13 通过。

之后扩大检查范围，增加路径穿越、CSRF、Origin、无效预览令牌等安全性场景，最终运行 **17/17 全部通过**。

本轮覆盖范围内 **没有复现出 Web App 产品功能缺陷**。但这不等于完成了安全审计，也不等于不存在缺陷。

## 4. 尚未覆盖和上线阻断项

- **正式公网端到端验证：未完成**。测试环境为 Actions 内部 127.0.0.1，不是 HTTPS 正式域名。
- **浏览器兼容性：未完成**。仅执行了 Linux Chromium；Safari、Firefox、移动浏览器尚待验收。
- **大文件与并发负载：未完成**。未对 100 MB 工作区极限、多个用户并发、断线续传和高压队列进行规模化测试。
- **数据持久化：未完成**。现有工作区仍依赖单进程内存索引，重启后不可恢复；需引入持久化元数据/任务队列。
- **文件解析隔离与安全：未完成**。没有对恶意 PDF/Office、解压炸弹、CPU/内存耗尽完成沙盒审计。
- **代理安全：未完成**。公网 TLS 配置、反向代理限流、日志隐私、帐号封禁与安全审查须单独验证。
